# 📝 My Daily Routine App (Laravel CRUD)

**My Daily Routine** adalah aplikasi web sederhana namun fungsional untuk mengelola jadwal kegiatan sehari-hari. Proyek ini dibangun menggunakan framework **PHP Laravel** untuk mendemonstrasikan implementasi konsep **CRUD (Create, Read, Update, Delete)** yang solid, validasi data, serta tampilan antarmuka (UI) yang responsif.

## ✨ Fitur Utama (Key Features)

* **Create (Tambah Data):** Menambahkan kegiatan baru beserta jam pelaksanaannya.
* **Read (Lihat Data):** Menampilkan daftar kegiatan harian dalam bentuk tabel yang rapi.
* **Update (Edit Data):** Mengubah detail kegiatan jika terjadi kesalahan atau perubahan jadwal.
* **Delete (Hapus Data):** Menghapus kegiatan yang sudah tidak diperlukan (dilengkapi dengan konfirmasi keamanan).
* **Responsive Design:** Layout tabel dan form otomatis menyesuaikan diri saat dibuka di HP (tabel dapat di-scroll, teks panjang otomatis turun ke bawah).
* **Empty State Handling:** Tabel otomatis disembunyikan jika belum ada data, memberikan tampilan yang fokus pada form input.

## 🛠️ Teknologi yang Digunakan

* **Backend:** Laravel Framework (PHP)
* **Frontend:** Blade Templating Engine, CSS3 (Flexbox & Custom Styling)
* **Database:** MySQL
* **Tools:** Visual Studio Code, Git
